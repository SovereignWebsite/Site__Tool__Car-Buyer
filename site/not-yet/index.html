What we cannot do yet

Every time we find something we do not know how to do, it goes here, with what we tried. When we find the way, it becomes a guide. Nothing is listed as done until it works.

WhatWhat we knowNext
Talk to Apple Intelligence from a pageWe know of no web interface that lets a page call it. Apple's Writing Tools and dictation work in any text box on an iPhone or Mac, and the My car page has a Speak button that uses the browser's own speech recognition where it exists.Ask Apple's developer documentation again each quarter; guide when found.
Hand someone an access token for the vault service, sealed to their keyThe CRM does it with a signed sealed code. This site's keeper holds no token and must not read one, so the owner has to give the token himself.Decision request to decisions.b: who issues tokens for car owners.
Create and save to a vault, tested end to endThe code is the CRM's pinned library. We have not yet run it against the live vault service from here.Owner tries it with a real token; we write what happens.
Look up a plate from the pageThe DVLA and MOT services refuse requests from a browser page and need a key held on a server.Waits for a keyed service.
